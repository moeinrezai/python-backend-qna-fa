۳۰ سؤال تخصصی Python برای مصاحبه Backend

این فایل شامل ۳۰ سؤال سطح بالا در مصاحبه‌های شغلی Backend با تمرکز بر Python است.

پاسخ‌ها کوتاه، مستقیم و مناسب مرور سریع قبل از مصاحبه طراحی شده‌اند.

---

مفاهیم پایه Python

سوال 1:  GIL چیست و چه تأثیری بر Backend دارد؟

پاسخ:

در واقع GIL مخفف عبارت Global Interpreter Lock است.

این مکانیزم اجازه می‌دهد فقط یک Thread در هر لحظه کد Python را اجرا کند.

برای عملیات CPU-Bound این محدودیت باعث کاهش Performance می‌شود.

برای عملیات I/O-Bound مانند درخواست‌های Web این محدودیت کمتر مشکل‌ساز است.

---

۲. تفاوت list و tuple چیست؟

پاسخ:

لیست (list) یک ساختار داده Mutable است.

تاپل (tuple) یک ساختار داده Immutable است.

در tuple سرعت دسترسی بالاتر است.

تاپل به‌عنوان Key در Dictionary قابل استفاده است به خاطر همین قابلیت immutable بودنش مقدار هش ثابت میمونه اما لیست چون تغییرپذیره هش ان قابل محاسبه نیست.

---

۳. کاربرد Decorator چیست؟

پاسخ:

دکوراتور Decorator یک تابع است که رفتار یک تابع دیگر را تغییر می‌دهد معمولا برای اضافه کردن یه سری ویژگی ها به یه تابع استفاده میشه بدون اینکه کد اون تابع رو دستکاری کنه.



از Decorator برای Logging، Authentication و Caching استفاده می‌شود.

<div dir="ltr">

```python
def log_decorator(func):
    def wrapper(*args, **kwargs):
        print(f"Calling {func.__name__}")
        return func(*args, **kwargs)
    return wrapper
```

</div>

۴. تفاوت Generator و list چیست؟

پاسخ:

جنراتور Generator مقادیر را به‌صورت Lazy تولید می‌کند.

لست list تمام مقادیر را در Memory ذخیره می‌کند.

جنراتور Generator برای داده‌های بزرگ بسیار بهینه‌تر است.

جنراتور Generator با کلمه کلیدی yield تعریف می‌شود.

نکته : در صورتی که در مصاحبه از شما پرسیده شد که جنراتور همیشه سریع تره باید بگید نه چون اکه نیاز به چندبار پیمایش داشته باشید جنراتور هزینه اضافی دارد و لیست در این حالت سریع تره.
نکته: جنراتور فقط تولید کننده نیست و میتونه مقدار هم دریافت کنه (coroutine)

۵. کاربرد Context Manager و with چیست؟

پاسخ:

در واقع Context Manager مدیریت منابع را بر عهده دارد.

این کلاس تضمین می‌کند که منابع به‌درستی باز و بسته شوند.

حتی اگر Exception رخ دهد، منابع آزاد می‌شوند.

معمولاً برای کار با فایل‌ها و Database Connection استفاده می‌شود.
این الگو جایگزین بلوک های try/finally تکراری میشود.

سوال چالشی : اگر context manager سفارشی نوشتی و در __enter__ خطایی رخ بدهد ایا __exit__ صدا زده میشه؟
جواب این سوال خیر چون اگه __enter__ استثنا بدهد . __exit__ هرگز فراخوانی نمیشود پس اگه منبعی را در __enter__ به صورت نیمه کاره ایجاد کردیم باید با try/finally ان مدیریت کنیم البته بهتره که از @contextmanager استفاده بشه که مدیریت ان ساده تر و تمیز تر میکنه.

۶. تفاوت *args و **kwargs چیست؟

پاسخ:

در واقع *args برای دریافت تعداد نامشخصی Argument موقعیتی استفاده می‌شود.

در واقع **kwargs برای دریافت تعداد نامشخصی Argument نام‌دار استفاده می‌شود.

این دو پارامتر انعطاف‌پذیری توابع را افزایش می‌دهند.

---

۷. تفاوت Mutable و Immutable چیست؟

پاسخ:

در واقع Mutable به معنای قابل تغییر پس از ایجاد است.

و list و dict از انواع Mutable هستند.

و Immutable به معنای غیرقابل تغییر پس از ایجاد است.

و tuple و str از انواع Immutable هستند.

---

۸. تفاوت Deep Copy و Shallow Copy چیست؟

پاسخ:

در Shallow Copy یک کپی سطحی از Object ایجاد می‌کند.

در Shallow Copy اشیای تودرتو به‌صورت Reference به اشتراک گذاشته می‌شوند.

در Deep Copy یک کپی کامل و مستقل ایجاد می‌کند.

برای Deep Copy از ماژول copy استفاده می‌شود.

---

۹. تفاوت List Comprehension و Generator Expression چیست؟

پاسخ:

لیست کامپریهنشن List Comprehension یک list کامل در Memory ایجاد می‌کند.

جنراتور اکسپرشن Generator Expression مقادیر را به‌صورت Lazy تولید می‌کند.

جنراتور اکسپرشن Generator Expression برای داده‌های بزرگ بهینه‌تر است.

۱۰. کاربرد Type Hints در Python چیست؟

پاسخ:

در واقع Type Hints نوع متغیرها و توابع را مشخص می‌کنند.

این قابلیت به Readability کد کمک می‌کند.

ابزارهایی مانند mypy از این قابلیت برای Static Analysis استفاده می‌کنند.

شی‌گرایی و ساختار کلاس

۱۱. تفاوت classmethod و staticmethod چیست؟

پاسخ:

در واقع classmethod به‌عنوان اولین پارامتر cls را دریافت می‌کند.

این متد به کلاس دسترسی دارد و می‌تواند Instance ایجاد کند.

در staticmethod هیچ پارامتر اجباری ندارد.

این متد نه به کلاس و نه به Instance دسترسی دارد.

سوال : ایا static method میتونه به اتربیوت های یک کلاس دسترسی داشته باشه ؟
پاسخ : به صورت خودکار نه اما میتونه به صورت دستی از اسم کلاس استفاده کنه اما اصلا توصیه نمیشه.

---

۱۲. تفاوت __init__ و __new__ چیست؟

پاسخ:

متد __new__ مسئول ایجاد Instance جدید است.

این متد قبل از __init__ فراخوانی می‌شود.

متد __init__ مسئول مقداردهی اولیه Instance است.

معمولا از __new__ زمانی استفاده میکنیم که بخوایم رو نحوه ساخت یه ابجکت کنترل داشته باشیم.

سوال : اگه متد __new__  یک ابجکت از کلاس دیگه ای برگردونه ایا __init__ کلاس فعلی اجرا میشه؟
پاسخ : خیر این __init__ فقط زمانی به صورت خودکار اجرا میشه که __new__ یه instance از همون کلاس یا subclass برگردونه.

۱۳. کاربرد Property در Python چیست؟

پاسخ:

پراپرتی Property امکان تعریف Getter، Setter و Deleter را فراهم می‌کند.

این قابلیت برای کنترل دسترسی به Attributeها استفاده می‌شود.

پراپرتی Property از Encapsulation پشتیبانی می‌کند.
در واقع به ما این امکان میده که با یک متد مثل اتربیوت برخورد کنیم .

سوال : فرق property با یک متد معمولی چیه؟
پاسخ : متد معمولی میشه با پرانتز صدا زد اما پراپرتی طوری طراحی شده که مثل اتربیوت استفاده بشه در واقع پراپرتی یه descriptor  که رفتار دسترسی به اتربیوت هارو کنترل میکنه.

۱۴. تفاوت is و == چیست؟

پاسخ:

== برای مقایسه مقدار دو Object استفاده می‌شود.

از is برای مقایسه Reference دو Object استفاده می‌شود.

از is بررسی می‌کند که آیا دو متغیر به یک Object در Memory اشاره می‌کنند یا خیر.
سوال : ایا is همیشه مربوط به ادرس حافظه یا ابجکته ؟
پاسخ : بهتره اینو نگیم در واقع میاد identity دو تا ابجکت مقایشه میکنه البته در cpython معمولا identity با ادرس حافظه مرتبطه  ولی تعریف پایتون بر اساس identity هست.

مدیریت حافظه و Performance

۱۵. مدیریت حافظه در Python چگونه کار می‌کند؟

پاسخ:
در Python مدیریت حافظه به‌صورت خودکار انجام می‌شود و برنامه‌نویس معمولاً مستقیماً حافظه را allocate و free نمی‌کند.
در واقع پایتون  objectها را در یک private heap نگهداری می‌کند و مدیریت این heap بر عهده‌ی Python Memory Manager است.

برای آزاد کردن objectها، مهم‌ترین مکانیزم Reference Counting است یعنی هر object تعداد referenceهایش را دنبال می‌کند. وقتی تعداد referenceها به صفر برسد، object می‌تواند آزاد شود.

علاوه بر Reference Counting، Python یک Garbage Collector هم دارد که برای پیدا کردن و حذف reference cycleها استفاده می‌شود چون در cycle ممکن است reference count هیچ‌وقت به صفر نرسد.

۱۶. کاربرد Garbage Collection در Python چیست؟

پاسخ:

در واقع Garbage Collector مسئول آزادسازی حافظه است.

این مکانیزم Reference Cycles را شناسایی و حذف می‌کند.

ماژول gc کنترل دستی این فرایند را امکان‌پذیر می‌کند.

۱۷. چگونه Performance یک برنامه Python را بهینه می‌کنید؟

پاسخ:

ابتدا با Profiler گلوگاه‌ها شناسایی می‌شوند.

از ساختارهای داده مناسب استفاده می‌شود.

از Generator برای داده‌های بزرگ استفاده می‌شود.

در صورت نیاز از C Extension یا Cython استفاده می‌شود.

Async و Concurrency

۱۸. تفاوت asyncio و threading چیست؟

پاسخ:

در threading از OS Threads استفاده می‌کند.

در asyncio از Event Loop و Coroutines استفاده می‌کند.

در asyncio برای I/O-Bound مناسب‌تر است.

در threading محدودیت GIL دارد.

---

۱۹. کاربرد async و await چیست؟

پاسخ:

در واقع async یک تابع را به‌عنوان Coroutine تعریف می‌کند.

و await اجرای تابع را تا پایان عملیات Async متوقف می‌کند.

این کلمات کلیدی برای نوشتن کد Non-Blocking استفاده می‌شوند.

---

۲۰.ایونت لوپ  Event Loop چیست؟

پاسخ:

در واقع Event Loop قلب asyncio است.

این حلقه وظایف Async را زمان‌بندی و اجرا می‌کند.

ایونت اوپ Event Loop عملیات I/O را به‌صورت Non-Blocking مدیریت می‌کند.

مفاهیم Web و Backend

۲۱. تفاوت WSGI و ASGI چیست؟

پاسخ:

WSGI یک استاندارد Synchronous برای Python Web است.

ASGI یک استاندارد Asynchronous برای Python Web است.

ASGI از WebSocket و HTTP/2 پشتیبانی می‌کند.

---

۲۲. کاربرد Dependency Injection چیست؟

پاسخ:

تزریق وابستکی یا Dependency Injection وابستگی‌ها را به‌صورت خارجی تزریق می‌کند.

این الگو Coupling بین اجزا را کاهش می‌دهد.

تست‌نویسی کد را ساده‌تر می‌کند.

Database و ORM

در واقع Connection Pooling اتصالات Database را مدیریت می‌کند.

به‌جای ایجاد اتصال جدید برای هر درخواست، از اتصالات موجود استفاده می‌شود.

Security

این فرایند مشخص می‌کند که کاربر چه کارهایی می‌تواند انجام دهد.
